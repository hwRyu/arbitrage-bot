# 신호 신뢰도 필터 — 설계 메모 (2026-10-30)

> 왜 이 문서가 있나: 2026-10-30 분석에서 봇이 잡은 익절·진입 신호의 대부분이 김프가 아니라 **두 거래소 반영 시차·호가 튐**
> 이라는 것이 확인됐다 (issues.md #1·#5, 아래 1번). 사용자가 가져온 "Persistence-Based Adaptive Anomaly Filter" 명세를
> 우리 문제에 맞게 옮긴 설계와, 데이터 수집 → 검증 → 연결 순서를 여기 적는다. **구현 전에 이 문서를 먼저 고친다.**

## 1. 문제 (무엇을 거르려는가)

봇은 0.25~2초마다 김프를 판단한다. 그 시계열에는 세 종류의 움직임이 섞여 있다.

| 유형 | 우리 사례 | 처리 |
|---|---|---|
| **Spike** — 급변 뒤 몇 초 안에 반납 | 바이비트가 먼저 튀어 생긴 김프 틈 (BLEND #36·#38 익절: 판단 +0.2% → 0.6초 뒤 바이비트 되돌림으로 −0.02%·−0.62%). 기준 안에 들어오는 유일한 한 줄이 얇은 '부스러기' 진입 신호 (10-30 놓침 13건, 확인 단계 신호의 86% 가 1초 못 넘김) | 제외 |
| **Level shift** — 급변 뒤 새 수준 유지 | 업비트가 실제로 재평가돼 분 단위로 유지되는 김프 변화 (BEAM #39 익절 +0.32%: 1분봉 기준 +0.4% 에피소드 중앙 1~2분) | 몇 초 뒤 인정 |
| **Noise** — 불규칙 왕래 | 호가 한 칸이 0.5~1% 인 코인의 칸 왕래 (XPL 97원 0.1칸, CAP 100원 1칸, DOGE 0.93%) | 신뢰도 낮게 유지 |

실측 근거 (2026-10-30, docs/issues.md):
- 보유 포지션 12초 스냅샷에서 순손익이 목표 0.2% 를 넘은 샘플은 **0개**인데 봇은 +0.237%·+0.214% 로 익절했다 → 익절 신호는 12초를 못 넘기는 틈이었다.
- 같은 3일을 1분봉(체결가)과 호가 스냅샷으로 비교하면 봉 기준 김프 변동이 호가 기준의 2~4배 (MINA·GMT·BEAM 은 호가 기준 1시간 0.6% 움직임 0%). 스크리너(1분봉)가 기회를 과대평가하는 이유.
- 30일 1분봉 50개 코인: 대형주(SOL·XRP·LINK)는 코인 몫 김프 표준편차 0.08~0.17%, 1시간 0.6% 왕복 거의 0. 소형주는 +0.4% 에피소드가 하루 수십 번이지만 60~95% 가 1분짜리.

결론: **"김프" 는 유지되는 차이로 정의해야 하고, 순간값만 보는 지금 판단은 잡음을 거래한다.** 고정 N초 대기 대신 아래 적응형 점수로 거른다.

### 원칙 (2026-10-30, 사용자 결정)
**운에 의존하는 신호는 거른다. 횟수가 줄어도 확실한 것만.** 틈(스파이크)은 상대 거래소가 우리 주문(0.4~0.6초)보다 빨리 따라오면
손해, 늦게 따라오면 이득이라 결과가 운이다 (BLEND #44 19:51 진입은 1초짜리 틈에서 +0.2%p 이득, 같은 구조의 익절 #36·#38·#42 는 손해).
이득이었던 틈도 거른다. 따라서 상수(Z·τ·컷)는 "기회를 더 잡는가" 가 아니라 **"틈에 들어가는 비율을 0 에 가깝게 하는가"** 로 정한다.

## 2. 설계 (명세 → 우리 변수)

입력 시계열 x(t): 코인별 **진입 김프(맨 앞 호가 기준, entry_premium_top)**, 포지션별 **청산 순손익%**. 샘플 간격 Δt 는 불규칙(0.25~2초). 필터는 원본을 바꾸지 않고 **신뢰도 점수 S(t) ∈ [0,1]** 만 낸다.

### 2-1. 변화량과 급변 판정
- d(t) = x(t) − x(t−1), v(t) = d(t)/Δt (초당 변화)
- 평소 변화폭: 최근 W_mad(기본 300초) 안의 |d| 의 **MAD**. `MAD_floor = max(MAD, tick%/2)` — 호가 단위 코인은 d 가 대부분 0 이라 MAD→0 이 되므로 한 칸의 절반을 하한으로 둔다 (kimp.premium.upbit_krw_tick).
- Z(t) = |d(t) − median(d)| / (1.4826 × MAD_floor). **Z ≥ Z_spike(기본 4) 이면 "급변 시작"**: 급변 기준값 x₀ = x(t−1), 급변폭 Δ = x(t) − x₀, 급변 시각 t₀ 를 기억한다. 가속도 a(t) = v(t) − v(t−1) 는 급변 시작 판정의 보조(완만한 추세는 a 가 작다).

### 2-2. 지속 증거 E(t) ∈ [0,1]  (급변 뒤 매 샘플)
급변 표시가 살아 있는 동안:
- **되돌림 비율** r(t) = (x(t) − x₀) / Δ 를 0~1 로 자른 값. 1 = 새 수준 그대로, 0 = 전부 반납. 가장 큰 가중 (우리 Spike 는 전부 r≈0 으로 끝난다).
- **방향 일관성** c(t): 급변 뒤 d(t) 부호가 Δ 와 같거나 0 인 샘플 비율 (최근 W_c = 10초).
- **안정성** s(t) = 2 − (급변 뒤 10초 |d| 중앙값 / MAD_floor) 을 0~1 로 자른 값 — 급변 뒤 흔들림이 평소 이하면 1, 평소의 2배면 0.
  (10-31 수정: 원안 `1 − min(1, …)` 은 평소 수준 흔들림을 0 으로 매겨 깔끔한 유지도 5초 넘게 걸렸다. c·s 는 **급변 뒤 샘플로만** 잰다.)
- E(t) = 0.6·r(t) + 0.2·c(t) + 0.2·s(t)

급변 표시가 없으면(완만한 변화) E(t) = 1.

**트리거 확장 (2026-10-31): 신호 켜짐 = 급변 시작.** 엔진은 매 샘플에 `signal_on`(김프 ≤ 기준 / 순손익 ≥ 목표)을 같이 넘기고, 거짓 → 참으로
바뀌는 순간을 Z 와 무관하게 급변 시작으로 본다 (x₀ = 직전 값, P → P_reset). 이유: 약식 검증(3번)에서 Z 급변만으로는 손해 신호의
3~8% 만 걸렸다 — 틈은 "변화가 평소보다 커서" 가 아니라 "기준을 **막** 넘어서" 위험하다. 켜짐으로 시작한 급변은 신호가 꺼지면 Spike
확정(P=0). 기준을 살짝 넘어 Δ 가 바닥(min_scale) 미만이면 되돌림 비율은 못 재고(r 미정 → 1 로 간주) 시간·일관성·안정성으로만 올라간다.

### 2-3. 지속성 점수 P(t) — 시간 감쇠 누적
샘플 간격이 불규칙하므로 ρ 대신 시간 감쇠: α = 1 − e^(−Δt/τ)
- P(t) = (1−α)·P(t−1) + α·E(t), τ 기본 8초
- 급변 시작 순간 P 를 P_reset(기본 0.1) 로 내린다 (급변 직후엔 믿지 않는다). 새 급변이 겹치면 다시 내린다.
- 되돌림이 r < 0.3 로 확정되면(급변분의 70% 이상 반납) 급변 표시를 지우고 P 는 0 으로 — Spike 확정.
- 급변 뒤 W_shift(기본 60초)가 지나도록 r ≥ 0.7 이면 급변 표시를 지우고 x₀ 를 새 수준으로 — Level shift 확정 (이후 완만한 변화로 취급).

### 2-4. 최종 점수와 연결
- S(t) = P(t) × Stab(t), Stab(t) = 최근 30초 변동성이 W_mad 변동성의 k배(기본 3) 아래면 1, 위면 선형 감소 → Noise 억제. 곱셈 이중 페널티를 피하려고 **Stab 은 P ≥ 0.7 일 때 가중을 절반으로** 줄인다 (검증 단계에서 조정).
- 컷 S_cut 기본 0.7. 익절: `순손익 ≥ 목표` **그리고** S ≥ S_cut 일 때만 FOK 매도. 진입: `김프 ≤ 기준` **그리고** S ≥ S_cut. 점수가 모자라면 `[익절 보류]`/`[진입 보류]` 에 `신뢰도 0.42 (급변 +0.45 반납 60%)` 식으로 이유를 남긴다.
- 상수는 셋뿐이다: τ, Z_spike, S_cut (나머지는 보조 가중). 전부 무차원(MAD 배수·초·점수)이라 코인별 손질이 없다.

### 2-5. 기대 동작 (운영값 τ=2.5초, S_cut=0.7, Z=3 — 2026-10-31)
```
순간 튐:   t=0.25 김프 −0.10→−0.55 (켜짐, P→0.1) · t=0.75 −0.15 (꺼짐/r<0.3 → Spike 확정, P=0)   → 주문 없음
유지:      t=0.25 같은 켜짐 · 되돌림 없이 유지 (E=1) → P = 1 − 0.9·e^(−Δt/τ) ≥ 0.7 은 Δt ≥ τ·ln3 ≈ 2.75초  → 약 2.7초 뒤 진입
흔들림:    유지는 되는데 급변 뒤 |d| 가 평소의 1.5배 (s=0.5, E=0.9) → 약 3.1초 · 반납 절반(r=0.5, E=0.7) → 영영 못 넘음
완만:      몇 분에 걸쳐 내려와 기준에 닿음 — 켜지는 순간은 똑같이 P→0.1 이라 ≈2.7초 기다린다 (켜짐 트리거의 대가, 틈과 구분 불가)
```

### 3-1. 약식 검증 결과 (2026-10-30 19:12 ~ 10-31 06:20 이벤트 기록, 코인 40개, 0.25초 격자)

신호 = 맨 앞 호가 김프가 직전 60초 중앙값보다 0.3%p 좋아진 순간. 결과 = 행동 0.6초 뒤 같은 김프의 불리한 변화 (우리 주문이 체결되는 사이).

| 행동 시점 | 익절형: 남는 신호 | 손해≥0.2%p | 진입형: 남는 신호 | 손해≥0.2%p |
|---|---|---|---|---|

| Z 급변 필터만 (원안, z3 τ8) | 92~97% | 15~16% | 92~97% | 15~16% |
| 1초 살아남으면 | 55% | 4% | 55% | 4% |

| 3초 | 39% | 2% | 39% | 2% |
| 5초 | 31% | 2% | 31% | 2% |

**구현된 게이트 그대로 재생 (τ 2.5 · Z 3 · 컷 0.7, 켜짐 트리거):**

| | 신호 | 게이트가 행동 | 행동분 0.6초 뒤 불리 평균 / 손해≥0.2%p | 차단분 (즉시 행동했다면) | 지연 중앙 |
|---|---|---|---|---|---|
| 익절형 | 4,184 | 1,614 (39%) | +0.008%p / **2%** (즉시 행동은 +0.082 / 17%) | +0.133%p / 27% | 2.75초 |
| 진입형 | 4,136 | 1,588 (38%) | +0.010%p / **2%** (즉시 행동은 +0.075 / 16%) | +0.122%p / 25% | 2.75초 |

차단된 쪽에 손해 신호가 몰려 있다(차단분 25~27% vs 행동분 2%) = 게이트가 틈을 골라낸다. 우리 코인(익절형→진입형): BEAM 25%→5% / 31%→10%,
BLEND 10%→0 / 4%→0, CAP 5%→0 / 5%→0, NIL 4%→0 / 10%→1%. BEAM 은 통과한 뒤에도 가장 흔들려(10%) 하루 뒤 컷 상향·제외 후보.

→ Z 급변만으로는 거의 안 걸린다 (틈의 변화폭이 평소 변화폭과 구분되지 않는 코인이 많다). **지속 시간이 결정적**이라 트리거를 '켜짐' 으로
확장했고, τ=2.5초(깔끔하면 2.7초 뒤)로 시작한다. 우리 코인: BEAM 25%→8%, CAP 5%→1%, NIL 4%→1% (5초 유지 기준). 상수 다듬기는
하루치 더 모은 뒤 — 익절·진입에 다른 τ 가 맞는지, 컷 0.8 이 더 나은지(남는 신호 vs 손해 비율)를 같은 표로 본다.

검증 때 같이 볼 것: 필터를 켜면 거래 수가 얼마나 주는가 (잡음을 빼면 진짜 기회가 몇 개 남는지가 전략의 기대값 시험이다), 평균 대기 시간, 거른 신호 중 뒤늦게 진짜였던 비율.

## 4. 한계

- 필터는 잡음에 거래하는 것을 막을 뿐 기회를 만들지 않는다. 호가 기준 0.6% 이상 **유지되는** 움직임은 CAP·BLEND·ZAMA 류에서 가끔 있을 뿐이다 (1번).
- 익절 대기 중 바이비트가 먼저 되돌아오면 기회는 사라진다 — 그게 맞는 결과다 (그 기회는 틈이었다).
- 수집은 맨 앞 호가뿐이라 '우리 수량이 닿는 줄' 은 모른다. 필터 검증은 맨 앞 김프로 하고, 실제 판단은 지금처럼 수량 기준 김프에 점수를 곱한다.
